The problem

Operators want to know why a GPU was flagged. A language model that can also take actions on a production fleet is a liability.

What I built

  • A tool-use loop on the Claude API that answers operator questions by calling Theta’s live tools instead of guessing.
  • The agent sees exactly the read-only tool registry that Theta’s MCP server exposes.
  • An independent critic pass audits each answer against the tool evidence, with one bounded revision.
  • Read-only by construction: no tool can fire an alert, drain a node, or change a threshold.

Results

15tests against an injected client, no network
0tools that can act on the fleet

What I learned

The strongest guardrail is structural. Prompting a model to be careful is weaker than never giving it a tool that can do damage.
