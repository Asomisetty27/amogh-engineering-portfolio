The problem

Build a working RISC-V processor from the RTL up and run it on real hardware.

What I built

  • Full RV32I base ISA with a 10-operation ALU and a 2-state FSM control unit (fetch, execute).
  • 32 × 32 register file with two read ports and one write port, dual-port memory.
  • 4-source PC mux (PC+4, jalr, branch, jal) and I/S/B/U/J immediate generation.
  • Synthesis, placement, routing, and static timing in Vivado; brought up on a Basys-3.

What I learned

Branch targets came out wrong. At the waveform level the cause was the PC-source mux not being gated by PCWrite. Asserting PCWrite only in the execute state fixed it.
